# Security policy

## Supported versions

Kiro Credit Optimizer is in alpha. Security fixes are made on the latest version on the `main` branch.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: open this repository's **Security** tab and choose **Report a vulnerability**. Please do not open a public issue for a suspected vulnerability.

Include the affected version, the steps to reproduce with synthetic data and the expected impact. Never include real balances, account identifiers, exports, credentials or session data.

## Scope

The CLI runs locally, makes no network requests and stores data only in the directory you choose. See [data handling](docs/DATA_HANDLING.md) for what it stores and how to protect or delete it.
